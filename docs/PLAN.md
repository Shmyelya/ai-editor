# План: AI-редактор

Восемь шагов. Один шаг — одна фича. Шаг заканчивается успешной сборкой схемы `test` через `Build.command` и одним коммитом. Следующий шаг не начинать, пока предыдущий не собран и не закоммичен. Код шага не расширять соседними фичами.

Время старта и финиша в README ставит автор. Этот план часы не назначает.

Вне плана: расширение «Поделиться», версия для Mac, экран настроек, ввод ключа, вложения, отдельный переключатель темы.

`Secrets.swift`, соль `test.groq.v1` и массив `obfuscatedKey` не менять. Открытый ключ никуда не писать. `Build.command` не менять.

## Общие решения

### Экраны и переход

Экранов три. Корень — редактор в `NavigationStack`, заголовок «Редактор». Кнопка в панели «История правок» открывает историю. Строка истории открывает просмотр этой правки. Назад — системная кнопка. Вкладок, шторок и четвёртого экрана нет.

Редактор: `test/EditorView.swift`, модель `test/EditorModel.swift`.
История: `test/HistoryView.swift`.
Просмотр: `test/EditDetailView.swift`.
Общий блок результата, не отдельный экран: `test/EditResultView.swift`.

Экран рисует состояние и вызывает методы модели. Запрос, разбор SSE, сравнение слов и запись в SwiftData живут вне `View`.

### Строки интерфейса

Все пользовательские строки и даты по-русски. Даты форматируются локалью `ru_RU`.

- Кнопка запуска: «Запустить». Пока идёт запрос, на её месте «Стоп».
- Ошибки: «Повторить».
- Копирование: «Скопировать».
- Режимы: «Результат» и «Изменения».
- Подписи выбора: «Действие», «Язык» и «Тон».
- Два блока перевода: «Было» и «Стало».
- Пустая история: `ContentUnavailableView` с текстом «Пока нет правок», без кнопки.
- Счётчик: `N/4000`, где `N` — `String.count` текущего поля.
- Ошибки запроса: «Нет сети», «Кончился лимит API», прочий сбой — «Не удалось получить ответ».
- Плейсхолдер поля: «Вставьте текст».
- Рядом с полем: «Вставить» и «Очистить».
- Панель клавиатуры: «Готово».
- Свайп в истории: «Удалить».

Отдельной подписи у индикатора загрузки нет: это системный `ProgressView`. Поиска и отдельного меню темы нет.

Цвета и шрифты системные. Удалённое слово — системный красный и зачёркивание, добавленное — системный зелёный, неизменённое — основной цвет. Своей палитры нет.

Списки и лента результата без `LazyVStack`. История — `List`. Редактор и просмотр — `ScrollView` и `VStack`.

### Ввод и действия

Действия по порядку, по умолчанию первое:

1. Перефразировать
2. Сократить
3. Перевести
4. Исправить ошибки

Языки по порядку, по умолчанию английский: английский, русский, немецкий, французский, испанский, итальянский, турецкий, китайский. Меню «Язык» видно только при «Перевести». Выбранный язык остаётся в модели экрана при смене действия. В запрос и в историю он попадает только для перевода.

Тоны по порядку, по умолчанию нейтральный: нейтральный, деловой, дружелюбный, простой. Меню «Тон» видно только при «Перефразировать». Выбранный тон остаётся в модели экрана при смене действия. В запрос и в историю он попадает только для перефразирования.

Типы выбора: `test/Models/EditorChoices.swift`. Хранимые значения действия: `paraphrase`, `shorten`, `translate`, `proofread`. Хранимые значения языка: `en`, `ru`, `de`, `fr`, `es`, `it`, `tr`, `zh`. Хранимые значения тона: `neutral`, `business`, `friendly`, `simple`.

Поле не длиннее 4000 символов (`String.count`): лишнее от конца отбрасывается. «Запустить» недоступна, если после обрезки пробелов и переводов строки текст пуст. В запрос и в историю уходит текст поля как есть, без отдельной обрезки краёв.

У поля плейсхолдер «Вставьте текст». Высота ограничена примерно восемью строками. Текст длиннее прокручивается внутри поля, чтобы результат оставался виден под ним. Рядом кнопки «Вставить» и «Очистить». «Вставить» — системный `PasteButton`: текст из буфера становится текстом поля. «Очистить» делает поле пустым. Обе не меняют уже показанный результат. Предел 4000 действует и на вставку.

Прокрутка экрана редактора скрывает клавиатуру. В панели клавиатуры кнопка «Готово» убирает клавиатуру.

### Запрос

Имя модели остаётся одной константой `openai/gpt-oss-120b` в `GroqChatService`. Тело: `model`, `stream: true`, `reasoning_effort: "low"`, `messages` из системного и пользовательского сообщений. Других полей нет.

На запрос — новая `URLSession`, таймаут 15 секунд. Общую сессию не вводить. «Стоп» отменяет задачу запроса. В результат берётся только `delta.content`. Дельты рассуждений на экран и в SwiftData не пишутся.

Разбор сбоев прежний: нет сети; кончился лимит API при HTTP 429 и при ответе Groq об исчерпании квоты или лимита; прочий сбой. Пустой ключ — прочий сбой. Декодированный ключ только в памяти на время запроса.

«Повторить» снова отправляет тот же исходный текст, то же действие, тот же язык и тот же тон. Черновик и выбранный тон, изменённые после запуска, на повтор не подменяются. «Повторить» есть только у ошибки запроса. «Стоп» ошибкой не считается: если символов ещё не было, это просто остановка.

Пока ответа нет — `ProgressView`. Дальше чистый текст растёт по мере дельт. Подсветки во время потока нет.

### Сравнение слов

Считается один раз методом `difference(from:)` и в SwiftData не хранится. Для перевода не считается.

Слово — кусок между пробельными символами, знаки препинания остаются при нём. Перевод строки (`\n`, `\r` и пара `\r\n`) — отдельный токен. Остальные пробельные символы токенами не становятся.

Лента из `resultTokens.difference(from: sourceTokens)`:

1. Смещения удалений — индексы исходных токенов. Смещения вставок — индексы токенов результата.
2. Идём по исходным и итоговым индексам. Сначала удалённый токен на текущем исходном индексе, затем вставленный на текущем итоговом, затем пара неизменённых, если оба индекса ещё внутри и это не удаление и не вставка.
3. Между соседними словесными токенами один пробел. Токен перевода строки остаётся переводом строки и пробела рядом не добавляет.

После конца потока, включая «Стоп» и ошибку, лента хранится в модели экрана. Переключение «Результат» / «Изменения» заново её не считает. На просмотре она считается один раз из сохранённых исходного текста и результата.

Переключатель из двух режимов появляется над результатом, когда поток уже кончился и текст результата непустой. Сразу выбран «Результат». Для «Перевести» переключателя нет: после потока те же два блока «Было» и «Стало».

«Скопировать» кладёт в буфер чистый текст результата. Режим на это не влияет. Кнопка видна, когда текст результата уже непустой, в том числе пока поток ещё идёт.

### История

Модель SwiftData — `TextEdit` в `test/Models/TextEdit.swift`. Поля только эти:

- `sourceText: String`
- `resultText: String`
- `action: String`
- `language: String?`
- `tone: String?`
- `createdAt: Date`

Отдельного поля идентификатора нет: переход использует `PersistentIdentifier`. Для действия не «Перевести» язык — `nil`. Для действия не «Перефразировать» тон — `nil`. Для перефразирования пишется хранимое значение тона, включая нейтральный. Контейнер приложения — `modelContainer(for: TextEdit.self)`. Старый контейнер чата не переносить: bundle id другой.

Пустой результат не записывается. Непустой пишется один раз в конце потока, по «Стоп» или по ошибке. Повторная запись по таймеру не нужна.

«Запустить» начинает новую попытку и забывает идентификатор предыдущей. Первая непустая запись этой попытки создаёт `TextEdit`. «Повторить» идентификатор не забывает: если запись попытки уже есть и новый результат непустой, обновляется только `resultText`. Дата, исходный текст, действие, язык и тон остаются. Пустой итог повтора уже сохранённый результат не затирает.

Список по `createdAt`, сначала новые. В строке: русское имя действия, одна строка исходного текста, дата. Если тон записан и узнаётся, имя тона стоит в той же строке действия через запятую: «Перефразировать, деловой». Для перевода в той же строке даты — русское имя языка. Свайп по строке показывает «Удалить» и удаляет правку из SwiftData. Если удалена запись текущей попытки, редактор забывает её идентификатор.

Просмотр показывает действие в заголовке. Если тон записан и узнаётся, имя тона стоит в том же заголовке через запятую. Дальше дата и тот же блок результата, что редактор после потока. Запуска с просмотра нет.

Ошибка сохранения показывается текстом «Не удалось сохранить» и не глотается пустым `catch`.

Новых возможностей нет. Ручные сценарии проходит автор и сообщает результат. Чаты в `ai-logs/` выгружает автор, без ключей и личных данных. Агент сценарии сам не проходит и логи не собирает.
